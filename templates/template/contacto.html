CONTACTO

Inicio Acerca Recursos

Explicacion corta de un flujo completo, por ejemplo: `/contacto -> contacto() -> render_template("contacto.html") -> navegador`.

Cuando el usuario entra a /contacto, la aplicación llama a la función contacto(). Esa función carga la página contacto.html usando render_template(). Después, el servidor envía esa página al navegador y el usuario la puede ver.
