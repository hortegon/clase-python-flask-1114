Explicacion corta del flujo:

La aplicación crea una lista en Python y la envía a render_template(). Después, Jinja usa un bucle para recorrer la lista y mostrar los datos en la página HTML. Finalmente, el navegador recibe el HTML terminado y lo muestra al usuario.
